Misiones

DJI Mini 4 Pro

Todavía no hay misiones. Crea un mapa o una órbita, o importa un área desde un archivo KML de Google Earth o Dronelink.

Sincronizar con el teléfono

Las misiones se guardan en tu repositorio privado Fidcom/mini4pro-app, en la rama misiones. La app Mini4Pro del Pixel lee la misma carpeta, así que lo que planifiques aquí aparece allá.

  1. Abre crear un token de GitHub.
  2. Nombre: Mini4Pro misiones. Expiración: la que prefieras, por ejemplo un año.
  3. En Repository access escoge Only select repositories y marca Fidcom/mini4pro-app.
  4. En Permissions → Repository permissions, pon Contents en Read and write.
  5. Pulsa Generate token, cópialo y pégalo aquí.

El token se guarda solo en este navegador. No se sube a ningún sitio más que a GitHub.
